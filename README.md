# Sales Performance & Product Analytics Dashboard (Excel)
## Project Overview

This project presents an interactive Sales Performance & Product Analytics Dashboard developed using Microsoft Excel.

The dashboard provides a detailed analysis of sales trends, product performance, regional sales distribution, and salesperson performance to support better business decision-making through data-driven insights.

The project demonstrates the use of advanced dashboarding, Pivot Tables, Pivot Charts, slicers, and data visualization techniques in Excel.

## Objectives
The main objectives of this project are:

• Analyze overall sales performance

• Monitor month-wise sales trends

• Identify top-performing products and regions

• Evaluate salesperson performance

• Compare sales quantity across product categories

• Build an interactive and user-friendly dashboard
